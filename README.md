# Fábrica de Conteúdo · LDX Live

Catálogo estático de soluções de aprendizagem e operação, desenvolvido com HTML, CSS e JavaScript Vanilla. Não requer build nem dependências.

## Executar localmente

Na raiz do projeto, execute `python3 -m http.server 8080` e acesse http://localhost:8080.

## Publicação

O site é servido diretamente pela raiz do repositório no GitHub Pages. Os arquivos usam caminhos relativos para suportar o endereço de projeto.

## Estrutura

- `index.html`: landing, catálogo, processo e detalhes acessíveis.
- `assets/js/catalog-data.js`: catálogo, necessidades e etapas do processo.
- `assets/js/app.js`: renderização, filtros e navegação por hash.
- `assets/css/styles.css`: identidade visual e responsividade.
- `fabrica_ldx_live_codex_handoff/`: documentação de produto e aceite.
