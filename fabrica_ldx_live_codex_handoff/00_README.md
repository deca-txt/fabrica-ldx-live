# Fábrica de Conteúdo · LDX Live — MVP Catálogo CONAREC

## Objetivo
Criar e publicar ainda hoje um catálogo web simples, responsivo, visualmente sofisticado e rápido de navegar para apresentação no CONAREC.

Este MVP NÃO inclui:
- integração com IA;
- captura de lead;
- backend;
- analytics;
- CMS;
- cases de cliente ainda não sanitizados.

Esses itens ficam preparados para próxima etapa.

## Entrega esperada
Uma aplicação estática publicada via GitHub Pages com:

1. Landing page curta;
2. CTA "Conheça nosso catálogo";
3. catálogo de soluções;
4. filtro por necessidade/dor;
5. cards de soluções;
6. detalhe de cada solução;
7. seção "Como trabalhamos";
8. estrutura pronta para incluir cases depois;
9. responsividade desktop/tablet/mobile;
10. navegação simples e premium.

## Stack obrigatória
- HTML5
- CSS3
- JavaScript Vanilla
- Git/GitHub
- GitHub Pages

Evitar:
- React
- Next.js
- frameworks CSS
- dependências desnecessárias
- build step
- npm obrigatório
