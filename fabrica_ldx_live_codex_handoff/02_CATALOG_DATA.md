# CATÁLOGO MESTRE — MVP

O catálogo deve ser data-driven em JavaScript.
Criar um único arquivo `catalog-data.js`.

Cada solução deve possuir:
- id
- name
- category
- shortDescription
- fullDescription
- idealFor[]
- needs[]
- capabilities[]
- outputs[]
- caseIds[]

---
